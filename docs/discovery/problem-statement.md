# Problem Statement

## Background

콘텐츠를 제작하기 위해서는
아이디어 기획부터 촬영, 편집, 자막, 캡션 작성, 업로드까지
여러 단계의 작업이 필요합니다.

현재 이러한 과정은 여러 도구와 앱을 오가며 진행되고 있으며,
콘텐츠를 제작하는 과정에서 특히 기획과 관리에 많은 시간이 소요됩니다.

또한 지속적으로 콘텐츠를 제작하기 위해서는
개별 콘텐츠뿐만 아니라 자신의 계정이 어떤 방향성을 가지고 있는지
파악하고 유지하는 것도 중요합니다.

## Problem

### 1. 콘텐츠 아이디어를 정리하고 결정하는 데 많은 시간이 걸립니다.

저는 콘텐츠 아이디어가 떠오를 때마다 메모장에 기록합니다.

새로운 콘텐츠를 기획할 때는 이전 콘텐츠와 내용이 잘 이어지는지,
비슷한 콘텐츠가 이미 있는지,
기존 콘텐츠가 어떤 방식으로 구성되어 있는지를 확인합니다.

이 과정에서 여러 앱과 콘텐츠를 반복적으로 확인해야 하며,
여러 아이디어 중 어떤 주제를 실제 콘텐츠로 발전시킬지 결정하는 데에도
많은 시간이 소요됩니다.

생각나는 아이디어는 많지만 이를 하나의 콘텐츠로 구체화하고
결정하는 과정이 체계적으로 정리되어 있지 않습니다.

### 2. 콘텐츠 제작 과정이 여러 도구로 분산되어 있습니다.

현재 콘텐츠 제작 과정에서는
아이디어 메모, 콘텐츠 검색, 기획, 촬영, 편집, 자막, 번역, 업로드 등
각 단계에서 서로 다른 도구와 서비스를 사용하고 있습니다.

이로 인해 이전 자료를 다시 찾거나,
같은 내용을 여러 도구에 반복해서 입력하는 등의
불필요한 작업이 발생합니다.

### 3. 계정의 정체성과 콘텐츠 방향성을 파악하기 어렵습니다.

콘텐츠를 지속적으로 제작하기 위해서는
내가 어떤 주제와 강점을 가진 크리에이터인지,
어떤 콘텐츠가 나의 계정과 잘 맞는지 파악하는 것이 중요합니다.

하지만 현재는 자신의 기존 콘텐츠를 종합적으로 분석하여
계정의 정체성과 콘텐츠 방향성을 확인할 수 있는 과정이 부족합니다.

따라서 새로운 콘텐츠를 기획할 때마다

- 어떤 주제를 계속 가져가야 하는지
- 새로운 주제를 시도해야 하는지
- 조회수가 높은 콘텐츠를 따라가야 하는지
- 기존 콘텐츠와 어떤 흐름으로 연결할 것인지

개별적으로 판단해야 합니다.

이러한 고민이 반복되면서 콘텐츠를 제작하는 것보다
콘텐츠의 방향성을 결정하는 데 더 많은 시간과 에너지를 사용하게 됩니다.

## Target Users

### Primary Users

- 개인 콘텐츠 크리에이터
- Instagram, YouTube 등 SNS를 운영하는 1인 크리에이터
- 콘텐츠 기획부터 제작, 업로드까지 직접 수행하는 크리에이터

### Secondary Users

- 콘텐츠 마케터
- 소규모 브랜드의 SNS 운영자
- 개인 SNS 채널을 운영하는 사용자

## Current Workflow

현재 콘텐츠 제작 과정은 다음과 같습니다.

아이디어 기록
→ 기존 콘텐츠 및 유사 콘텐츠 검색
→ 콘텐츠 주제 및 방향성 결정
→ 콘텐츠 기획
→ 영상 촬영
→ 영상 편집
→ 자막 작성
→ 영어 자막 번역
→ 인트로 및 본 영상 편집
→ 캡션 작성
→ 콘텐츠 업로드

## Why Existing Solutions Are Not Enough

현재 사용하고 있는 도구들은
콘텐츠 제작 과정의 특정 단계에는 도움을 주지만,
아이디어를 발견하고 정리하는 과정부터
콘텐츠 제작, 업로드, 성과 분석까지의 전체 흐름을 하나로 연결하지는 못합니다.

또한 기존 콘텐츠를 기반으로
크리에이터의 콘텐츠 정체성과 방향성을 분석하고,
그 결과를 다음 콘텐츠 기획으로 연결하는 과정이 부족합니다.

따라서 콘텐츠 제작 과정 전체를 연결하고,
크리에이터의 기존 콘텐츠와 방향성을 바탕으로
다음 콘텐츠를 기획할 수 있도록 돕는 새로운 접근이 필요합니다.

## Goal

콘텐츠 아이디어를 고민하고 결정하는 데 소요되는 시간을 줄이고,
아이디어 수집부터 콘텐츠 기획, 제작, 업로드 및 성과 관리까지의
과정을 하나의 흐름으로 연결하는 것을 목표로 합니다.

또한 기존 콘텐츠와 성과 데이터를 분석하여
크리에이터가 자신의 콘텐츠 정체성과 강점을 파악하고,
이를 바탕으로 일관된 콘텐츠 방향성을 만들어갈 수 있도록 지원합니다.

궁극적으로 크리에이터가 반복적인 기획과 관리에 사용하는 시간을 줄이고,
콘텐츠 제작 자체에 더 집중할 수 있도록 돕는 것을 목표로 합니다.
