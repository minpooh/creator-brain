# 🧠 creator brain
> An AI-powered workspace that helps creators discover their identity,
> find their content direction, and plan what to create next.
>
> 🚧 This project is currently in the planning phase.

---

## ✨ About

Creator Brain은 크리에이터가 자신의 콘텐츠와
관심사, 경험을 바탕으로

**"나는 어떤 크리에이터인가?"**

를 발견하고,

**"앞으로 어떤 콘텐츠를 만들어야 하는가?"**

를 결정할 수 있도록 돕는 AI 기반 콘텐츠 기획 웹 애플리케이션입니다.

기존 콘텐츠를 분석하여 크리에이터의 정체성,
강점, 콘텐츠 패턴을 발견하고,
이를 바탕으로 콘텐츠 방향성과 다음 콘텐츠 아이디어를 제안합니다.

아직 콘텐츠를 제작하지 않은 사용자는
자신의 관심사와 경험을 입력하여
Creator Brain을 시작할 수 있습니다.

---

## ☠️ Problem

콘텐츠를 지속적으로 제작하기 위해서는
단순히 콘텐츠를 만드는 것뿐만 아니라

- 나는 어떤 콘텐츠에 강점이 있는지
- 어떤 주제를 계속 가져가야 하는지
- 새로운 주제를 시도해야 하는지
- 다음에는 어떤 콘텐츠를 만들어야 하는지

를 지속적으로 판단해야 합니다.

하지만 기존 콘텐츠가 쌓이더라도
자신의 콘텐츠를 종합적으로 분석하여
계정의 정체성과 방향성을 파악하기는 어렵습니다.

결과적으로 새로운 콘텐츠를 기획할 때마다
무엇을 만들어야 할지 다시 고민하게 되고,
아이디어를 결정하고 구체적인 콘텐츠로 발전시키는 데
많은 시간이 소요됩니다.

---

## 💡 Solution

Creator Brain은 크리에이터의 콘텐츠를 분석하여
콘텐츠 제작의 다음 단계를 제안합니다.

```text
Existing Content
       ↓
AI Analysis
       ↓
Creator Identity
       ↓
Content Direction
       ↓
Content Ideas
       ↓
Content Planning
```

아직 콘텐츠가 없는 사용자는
간단한 질문을 통해 자신의 관심사와 경험을 입력하고
Creator Identity를 발견하는 것부터 시작할 수 있습니다.

---

## 🚀 Planned Feature

### Creator Identity

기존 콘텐츠 또는 사용자의 관심사와 경험을 분석하여

- Creator Identity
- Content Pillars
- Content Strengths
- Content Patterns

를 도출합니다.

### Content Direction

Creator Identity와 콘텐츠 강점을 바탕으로
앞으로 발전시키면 좋을 콘텐츠 방향을 제안합니다.

### Content Ideas

사용자의 콘텐츠 방향에 맞는
다음 콘텐츠 아이디어를 추천합니다.

### Content Planning

선택한 아이디어를 실제 제작 가능한 콘텐츠 기획으로 발전시킵니다.

- Title
- Hook
- Key Message
- Story Flow
- Shot Ideas
- Content Management

제작한 콘텐츠를 등록하고
콘텐츠 및 성과 데이터를 관리합니다.
