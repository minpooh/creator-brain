# 🧠 creator brain
> An AI-powered workspace for creators to plan, create, and manage content.
>
>  🚧 This project is currently in the planning phase.

---

## ✨ About

Creator Brain은 콘텐츠 크리에이터가 아이디어를 기획하고,
AI의 도움을 받아 콘텐츠를 제작하며,
업로드와 관리를 하나의 워크플로우에서 진행할 수 있도록 돕는 웹 애플리케이션입니다.

이 프로젝트는 실제 콘텐츠 제작 경험을 바탕으로,
복잡하게 흩어진 작업 과정을 하나의 서비스로 통합하여
크리에이터가 콘텐츠 자체에 더 집중할 수 있도록 돕는 것을 목표로 합니다.

---

## ☠️ Problem

콘텐츠 제작 과정은 여러 앱을 오가며 진행됩니다.

- 아이디어는 메모장
- 촬영은 카메라
- 편집은 CapCut, Premire Pro, Edits..
- AI는 ChatGPT, Gemini..
- 업로드는 Instagram, Youtube..

이처럼 작업이 분산되어 있어
기획과 관리에 많은 시간이 소요됩니다.

각 단계가 서로 연결되어 있지 않아
작업을 반복하거나 이전 내용을 다시 찾아보는 시간이 자주 발생합니다.

Creator Brain은 이러한 워크플로우를 하나의 서비스에서 관리하는 것을 목표로 합니다.
